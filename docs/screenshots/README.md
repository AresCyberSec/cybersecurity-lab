# Lab Screenshots

This directory contains screenshots documenting the development and configuration of the cybersecurity laboratory.

Screenshots will be added as different components of the lab are configured and tested.

## Planned Documentation

* Virtual machine configuration
* Network configuration
* Linux server setup
* UFW firewall status
* Suricata installation and operation
* Security alerts
* Network monitoring
* Lab network topology
* Security testing results

Sensitive information such as passwords, private keys, and personal network information will be excluded or redacted.
