# Cybersecurity Lab 🛡️

A hands-on cybersecurity lab built with Linux virtual machines for practicing system administration, networking, security monitoring, and defensive cybersecurity.

## 🏗️ Lab Architecture

The lab is designed around an isolated environment containing:

* **Kali Linux** — Security testing and assessment
* **Linux Server** — Server administration and defensive security
* **Target VM** — Controlled system used for security testing

### Planned Network

## 🔐 Security Components

The lab includes hands-on work with:

* Linux system administration
* UFW firewall configuration
* SSH security
* Network monitoring
* Suricata IDS
* Log analysis
* Network segmentation
* Vulnerability assessment
* Security hardening

## 🎯 Objectives

The goal of this project is to build practical cybersecurity skills through a controlled environment where security configurations, monitoring systems, and defensive techniques can be safely tested.
